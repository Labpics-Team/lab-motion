# Первичные материалы серверной приёмки Motion

`portability/witness-to-portable-map.json` связывает девять ссылок исторического свидетеля r12 с исходными файлами. Текущая `portability/portable-file-map.json` содержит исходные идентичности, физические пути и рецепты восстановления. Исходники закреплены постоянными Git-ссылками в `portability/source-and-existing-url-map.json`.

Полные raw/journal, исправные контроли и исторические отказы сохранены. У архива `method5dc/evidence/frame-first-publication-closure/maxN1024.ndjson.gz` целый файл в этом Git-дереве отсутствует: его исходные байты хранятся в трёх частях. Карта указывает физический `.parts.json`, SHA частей и смещения. Gzip не перекодирован и не сжат заново.

Скачайте `.parts.json` по точному коммиту. Его SHA-256 — `c32eb1fe6d805d598db43fbe767a6d4af2aa5b8029309671676e55e1a7d93139`. Для восстановления выполните `python hydrate-segments.py --manifest <карта.parts.json> --manifest-sha256 c32eb1fe6d805d598db43fbe767a6d4af2aa5b8029309671676e55e1a7d93139 --github --out <собственный-каталог>/maxN1024.ndjson.gz`. Нужен штатный `gh` с доступом к репозиторию. Для локальных Git-объектов вместо `--github` доступен `--git-dir <каталог-Git>`. Готовое имя появляется атомарно после всех проверок; существующий результат не перезаписывается.

Восстановленный gzip содержит 44 790 883 байта, SHA-256 `298745c674a4f2f9eabbb24abe9ccf82e7d9e467e9f5492b4ee5ce9e59b260f7` и Git blob `5becf6dab5ef9aa4ae3d340818e3811c01b583bc`. Прежняя квитанция распакованного потока — 934 439 111 байт, SHA-256 `15104fb3226920a8db37133ede193be3fa67f21c99bd7f579002aa6266a0b678` — переносится по точным сжатым байтам. Загрузчик gzip не распаковывает; нового декодирования этот перенос не утверждает. Обычный gzip/NDJSON потребитель после восстановления получает прежний файл.

`portability/portable-file-map-original-919.json` сохраняет историческую карту локального непоставленного кандидата `9195223`. Её прежний путь большого архива не является текущим физическим путём; используйте текущую карту. Остальные исходные файлы сохранены буквально. Локальные пути внутри квитанций сохраняют исторический смысл; новые результаты создавайте в собственном каталоге.

Около 700 МБ уникальных исходных байтов хранятся в отдельной ссылке `refs/evidence/production-primary-20261001`. Обычный fetch веток heads её не включает; явный custom fetch или mirror включает данные. Npm-пакет эти материалы не содержит. Перенос не создаёт приёмки метода, фактической производительности или выпуска и не добавляет зарегистрированных временных наблюдений.
