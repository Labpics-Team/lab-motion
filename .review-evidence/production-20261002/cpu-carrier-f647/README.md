# Серверный опыт: представление свидетельств CPU

Роль: справка (Diátaxis).

Здесь сохранены полные независимые отчёты по методу измерения и последствиям
изменения для исходника `f6476ae990254f606faf97f80afe41965bec2fb2`.
`bindings.json` связывает каждое первичное тело с доставленным файлом либо
участником архива. Полные отчёты находятся по исходным именам `REPORT.md`
в карте. Буквальные тексты и исторические отказы сохранены без исправлений.

Архивы `source.tar.gz` восстанавливают исходные `source.tar` обычной распаковкой
gzip; карта содержит размеры и SHA-256 обоих представлений и всех639участников.
Одинаковые тела используют прежние файлы этой же ветки. Это перенос по точным
байтам, а не повторное исполнение: свежий запуск на f647 указан только у
локальных проверок. Переданный узкий runtime witness относится к5a4с тем же
полным Git tree. Большое прежнее хранилище raw повторно не декодировалось.

Все три отрицательных диагностических опыта сохранены: одноразовый SHA-вызов
и подготовленный шаблон не дали подтверждённого выигрыша и отсутствуют в
итоговом исходнике. RLE сохраняет все endpoints; его выигрыш по размеру
не выдаётся за исправление временного отказа удалённого CI.

Синтетическая оценка места относится к прежней успешной форме. Она не доказывает
безусловную границу фактических браузерных трасс. Регистрация эпохи7 — метаданные
до наблюдений; сама по себе она не является калибровкой или результатом A/B.
Изменение отдельной ветки отчётов не разрешает слияние, выпуск или активацию.

Фактический CI этого исходника сохранил5018успешных проверок и один отказ
по прежнему общему30секундному лимиту авторского теста пяти контрпримеров
(32,154с). Полный CodeRabbit содержит одну ошибку покрытия настоящего
нативного счётчика и два предупреждения; краткая русская документация принята.
Оба состояния сохранены буквально и остаются открытыми для данного исходника.
