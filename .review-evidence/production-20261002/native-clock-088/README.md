# Счётчик серверного опыта — исходник 088

Роль: справка (Diátaxis).

Каталог содержит полные независимые отчёты по методу и последствиям изменения,
их исходные наблюдения, привязки, точный снимок исходников и первичные проверки.
Все доставленные тела перечислены в `bindings.json` с исходным путём, размером
и SHA-256. Исходные отчёты сохранены побайтно, включая исторические отказы.

Две рецензии относятся к частному `CLOCK_THREAD_CPUTIME_ID` и сообщённому Linux
времени исполнения потока. Прежние 2000 ns — наружное расширение сообщённого
счётчика, без физического сертификата. Калибровка и быстродействие кандидата ещё
не доказаны. Локально 5014 тестов прошли; удалённый CI сохранил 5013 PASS и один отказ
по прежним 30 секундам. Полный CodeRabbit сохранил одну ошибку и два предупреждения
документации/границ. Эти открытые гейты не выдаются за общий допуск.

Чтобы восстановить манифест рецензента, скопируйте тела в соответствующие исходные
пути из карты либо используйте собственный корень с той же относительной структурой.
Для `measurement/source/*` распакуйте доставленный архив
`primary/files/tmp/motion-native-clock-successor-088fbc60-20261002/source.tar.gz`
в `measurement/source`. В архиве 639 файлов; для каждого `sourceArchiveClosures`
задаёт имя участника, размер и SHA-256. Остальные ссылки PRIMARY восстановимы
через `files`. Полный прежний большой архив повторно не декодируется и не меняется.

Исходные данные эпох 5/6 и отчёты 185 остаются в родительском каталоге этой ветки.
Результаты другого счётчика или версии не переносятся по совпадению названия.
Изменений продукта, слияния, выпуска, развёртывания и активации здесь нет.
