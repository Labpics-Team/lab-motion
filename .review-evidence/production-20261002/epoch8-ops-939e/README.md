# Серверный результат и штатная остановка

Роль: справка.

Эпоха 8 исполнялась один раз на fe092. Пилот потребовал 1240 прогонов при пределе 1024:
мощность не достигнута. Оператор остановил оставшуюся диагностику; неизменные raw,
журнал, времена, причина остановки и полный независимый отчёт сохранены.
Это UNPROVEN: A/B, положительная калибровка и измерения кандидата не достигнуты.

Отдельный исходник 939e завершает запуск после невозможного N и сохраняет данные
при SIGINT/SIGTERM. Его контрольная первичка и два полных независимых отчёта
сохранены отдельно от фактических наблюдений fe092.

bindings.json связывает исходные пути, размеры и SHA с буквальными копиями,
gzip или членами SOURCE. Для gzip нужно проверить сжатые байты, затем полные
восстановленные байты и SHA. Исторические depot и оригиналы не меняются.
Одинаковые тела используют прежние локаторы без нового чтения старой большой
первички. Product GO, mobile, физическая точность CPU и лидерство не заявлены.
