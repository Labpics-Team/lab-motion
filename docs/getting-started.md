# Начало работы

Установите библиотеку:

```sh
pnpm add @labpics/motion
```

## Первое движение

```typescript
import { animate } from '@labpics/motion';

animate(document.querySelector('.card')!, { opacity: 1, y: 0 });
```

Одно значение задаёт цель. Повтор той же цели сохраняет текущее движение.
Новая цель подхватывает положение и скорость; другие свойства продолжают
работать. Библиотека сама выбирает нативное исполнение либо общий JavaScript-цикл.

Массив задаёт явную траекторию и запускается заново при каждом вызове:

```typescript
animate('.card', { x: [0, -6, 6, 0] }, { duration: 240 });
```

Времена задаются в миллисекундах. Без параметров обычная цель использует пружину.
`duration` переключает вызов на временную кривую; `ease` может быть CSS-именем,
кортежем cubic-bezier или чистой функцией. Авторская многоточечная траектория
без опций длится 200 мс и использует линейную интерполяцию.

## Компонент и очистка

Область ограничивает селекторы и владеет анимациями, подписками и дочерними
областями. Создавайте её при монтировании компонента, освобождайте при удалении.

<!-- motion-component-example -->
```typescript
import { scope } from '@labpics/motion';

export function mountMotion(root: HTMLElement) {
  const motion = scope(root, { duration: 180, ease: 'ease-out' });
  motion.animate('.item', { opacity: [0, 1], y: [8, 0] }, { stagger: 25 });
  motion.on('[data-replay]', 'click', () => {
    motion.animate('.item', { x: [0, -4, 4, 0] }, { duration: 240 });
  });
  return () => motion.dispose();
}
```

`dispose()` останавливает принадлежащие области движения в текущей позе и
снимает её обработчики. Поздние вызовы освобождённой области ничего не запускают.
Удалением DOM, фокусом, доступными подписями и данными продолжает владеть компонент.
Для повторного монтирования создайте новую область.

В React вызовите `mountMotion(ref.current)` из эффекта и верните полученную
функцию очистки. В Solid зарегистрируйте её через `onCleanup` после `onMount`.
Импорт пакета сам по себе не обращается к DOM.

## Завершение и отмена

```typescript
const exit = animate('.dialog', { opacity: 0 }, { duration: 180 });
const result = await exit.finished;

if (result.status === 'finished') {
  document.querySelector('.dialog')?.remove();
}
```

`finished` различает достигнутую цель и прерванный прогон. Ошибка исполнения
отклоняет promise. Обычная отмена возвращает `{ status: 'stopped' }`.

Контролы: `pause()`, `play()`, `seek(milliseconds)`, `stop()` и `finish()`.
`seek` сохраняет состояние паузы. `stop` оставляет текущую позу, `finish` применяет
конечную цель. Завершённый controller больше не создаёт эффекты.

Новый вызов получает управление даже при повторе той же цели. Прежний controller
завершается как `stopped`, но сама траектория продолжает исполняться без перезапуска.
Поэтому очистка старого компонента не отменяет движение его преемника.

## Раскладка и последовательности

`layout(root, mutate)` показывает переход между двумя состояниями DOM.
Измените данные или классы в `mutate`; обновление выполняется один раз.
При отсутствии View Transitions или при уменьшенном движении применяется
конечная раскладка без промежуточных снимков.

`sequence()` связывает несколько движений одной временной шкалой:

```typescript
import { sequence } from '@labpics/motion';

const intro = sequence([
  ['.title', { opacity: [0, 1] }, { duration: 180 }],
  ['.content', { y: [12, 0], opacity: [0, 1] }, { at: '<', duration: 280 }],
]);
```

Шаги идут последовательно. `at: '<'` начинает шаг вместе с предыдущим,
числовой `at` задаёт миллисекунду общей шкалы. Пересекающиеся движения одного
свойства в одной последовательности отвергаются до записи в DOM.
