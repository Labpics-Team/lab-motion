# Превью движения

Круги непрерывно проходят по виткам неподвижной пружины. Разница в размере,
светлоте и перекрытиях создаёт объём. Общий план сменяется деталями; кульминация —
крупный передний изгиб и торможение потока, затем камера возвращается к целой форме.
В кадре нет надписей. Звук подчёркивает ускорение, склейки и замедление.

Видео запускается по нажатию. Это авторская параметрическая анимация, отрендеренная
в SVG-кадры, а не запись браузера, проверка физического solver или демонстрация
compositor-производительности.

## Пересобрать

Нужны Node.js, Python с NumPy и SciPy, FFmpeg с librsvg, libx264 и AAC.
Установка зависимостей библиотеки для рендера не требуется.

Из корня репозитория:

```sh
node scripts/render-readme-preview.mjs /tmp/lab-motion-film
python3 scripts/preview/sound.py /tmp/lab-motion-film/sound.wav
ffmpeg -y -framerate 60 -i /tmp/lab-motion-film/%04d.svg -i /tmp/lab-motion-film/sound.wav -map 0:v:0 -map 1:a:0 -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -c:a aac -b:a 160k -ar 48000 -movflags +faststart site/public/media/motion-preview.mp4
cp /tmp/lab-motion-film/poster.svg site/public/media/motion-poster.svg
```

Для версии без звука можно удалить аудиодорожку без повторного кодирования изображения:

```sh
ffmpeg -y -i site/public/media/motion-preview.mp4 -c:v copy -an -movflags +faststart /tmp/motion-preview-silent.mp4
```

## Изменить композицию

- `scripts/preview/helix-geometry.mjs` задаёт винтовую линию и круги.
- `scripts/preview/timeline.mjs` задаёт длительность, темп потока, склейки и движение камеры.
- `scripts/render-readme-preview.mjs` отвечает за светлоту, порядок перекрытия и кадрирование постера.
- `scripts/preview/sound.py` синтезирует звуковое сопровождение без внешних записей. При изменении тайминга фильма согласуйте с ним звуковые акценты.

Временная шкала непрерывна через склейки. За цикл поток проходит целое число интервалов
между кругами; начальный и конечный набор позиций совпадает. Скорость остаётся положительной,
а смены её величины сглажены. Постер отрисовывается тем же скриптом.

Перед заменой проверьте весь ролик: общий план должен читаться как пружина,
крупный план должен содержать изгиб, соседние круги не должны сливаться в цепочки.
Единичные перекрытия переднего и заднего витков — часть пространственной проекции.
Проверьте возврат к началу, воспроизведение со звуком и без него, а также постер
в размере README. Версии кодеков могут менять байты готового файла.
