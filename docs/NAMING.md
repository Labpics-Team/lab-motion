# Именование Lab Motion

Файлы и публичные имена называются по назначению. Название реализации
остаётся внутри модуля, который ею управляет.

## Файлы

В `src/`, `test/`, `scripts/` и `docs/` используйте `kebab-case`:
`motion-value.ts`, `solver-finiteness-fuzz.test.ts`. Составные расширения
`.test.ts` и `.spec.ts` сохраняются. Для заглавных названий справочных
документов допускается `NAMING.md`.

## Публичные модули

[Экспорты пакета](../package.json) определяют доступные импорты. Субпути
называются по возможностям: `./svg-morph`, `./compositor/follow`.
Каждый экспорт разрешается в исходный модуль. Внутренние `src/internal/`
остаются вне публичной поверхности.

Для корневого импорта используйте `@labpics/motion`. Фреймворк-биндинги
имеют имена своих платформ, например `./react` и `./svelte`.
Их реестр находится в
[инвентаризации](../scripts/naming-inventory.mjs), а доступность
проверяется по экспортам пакета.

Актуальные субпути, биндинги и имена CSS можно посмотреть командой:

```sh
node scripts/naming-inventory.mjs
```

## CSS

Собственные CSS-переменные библиотеки начинаются с `--lab-motion-`.
Библиотека использует `--lab-motion-value` и `--lab-motion-progress`.
Переменные оформления интерфейса задаёт приложение, которое его отображает.
