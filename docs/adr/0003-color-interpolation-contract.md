# ADR 0003: цвет как анимируемое значение

Статус: принято. Область: `@labpics/motion/value`, issue #319.

## Контекст

Lab Motion уже интерполирует заданные CSS-цвета. Это необходимая часть исполнения
анимации, но не основание переносить в него выбор палитры, цветовые ограничения
или сертификацию Lab Colors.

Режим `space: 'linear'` использует γ=2, а не точную кусочную передаточную функцию
sRGB. Сходство формул не доказывает заданный допуск погрешности, а ошибка
кодированного канала не является порогом визуальной различимости.

## Решение

Сохраняем существующую математику, значения по умолчанию и публичные имена.
Исправление недостоверного обещания не требует изменения уже отображаемых цветов.
`linear` документируется как имя режима γ=2, не как CSS `srgb-linear`.
Ни численная близость к точному линейному свету, ни визуальная неразличимость
не обещаются. Независимый sRGB-оракул живёт только в тестах.

Контракт RGB-пути: `sqrt(from² * (1-t) + to² * t)` для `linear`, обычный lerp
кодированных каналов для `srgb`. Каналы округляются до целых; alpha интерполируется
отдельно без premultiplication. Два HSL-значения используют HSL-интерполяцию
и кратчайший путь hue независимо от `space`. Формат входа и режим смешения
не означают соответствие всей процедуре CSS Color 4.

Lab Motion владеет временем, progress, прерыванием и исполнением объявленного
перехода. Он не обещает сохранения контраста, читаемости, идентичности или чистоты
промежуточных цветов. Эти требования принадлежат цветовому контракту приложения
и Lab Colors. Корректность двух конечных цветов сама по себе не удостоверяет путь.
Для гарантии на всём переходе требуется отдельный контракт, учитывающий также
интерполяцию, округление и прерывание; обычный tween такой гарантии не выдаёт.

Зависимость на Lab Colors, новые цветовые пространства и новый способ исполнения
в это исправление не входят. Это не общий запрет на современные CSS-цвета:
их поддержка оценивается как отдельная пользовательская возможность с явной
семантикой и существующими бюджетами, а не как следствие этого дефекта.

## Проверка и последствия

`test/value-color-precision.test.ts` сравнивает реальный API с независимой точной
sRGB EOTF и фиксирует область измерения: все byte-пары при midpoint. Этот конечный
корпус не выдаётся за доказательство максимума на непрерывном домене. Существующие
тесты поведения, конечности и границ импортов остаются обязательными.

Для воспроизводимого сравнения стоимости подготовки и численного смешения:

```bash
pnpm build
node bench/color-interpolation.mjs
```

Это микробенчмарк Node/V8, не сравнение качества цветов, плавности интерфейса
или производительности браузеров. Результаты не определяют функциональную
корректность и не являются новым CI-порогом. Точная EOTF остаётся кандидатом
для отдельного изменения контракта, а не скрытой заменой существующего режима.

Нормативный источник точной передаточной функции:
[CSS Color 4, sRGB](https://www.w3.org/TR/css-color-4/#predefined-sRGB).
