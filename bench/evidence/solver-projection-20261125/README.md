The derived source is checked at build; no additional runtime generator or dependency. Deliberately appended stale output was rejected by --check, then restored and verified. Alternatives explored on the experimental combined curve baseline: shared modal runtime functions passed numerical tests but violated projection and core size caps; direct canonical solve with reused output reduced root size but cold compile 7.185 -> 9.0815 ms; value-only runtime mode also violated small consumer caps and cost 7.1915 -> 8.5852 ms. Forced Terser inline did not recover small-consumer sizes. These alternatives are not production code. Chosen approach is source-level specialization rather than a second maintained formula. Background: Yoshihiko Futamura, Partial Evaluation of Computation Process (https://doi.org/10.11309/jssst.21.343).
