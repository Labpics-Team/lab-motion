# Исходники частного CPU-счётчика

Роль: справка (Diátaxis).

`include/` содержит четыре неизменённых заголовка Node-API из Node.js `v24.19.0`,
[официальный каталог `src`](https://github.com/nodejs/node/tree/v24.19.0/src).
Уведомление об авторских правах участников Node.js и Joyent сохранено в
[LICENSE](./LICENSE). Заголовки нужны для сборки частного инструмента измерения;
npm-пакет библиотеки их не включает.

Команды запуска — в [справочнике инструмента](../../../docs/server-profile.md).
SHA-256 каждого заголовка и исходника C закреплён в
[`SERVER_PROFILE.clockError.nativeSourceFiles`](../server-profile-registration.mjs).
Счётчик собирается до регистрации. Сведения о полученном бинарном файле,
компиляторе, флагах, libc и PID/TID сохраняются в `engineClock`.
Обычный импорт модуля не требует компилятора. Номинальное разрешение `clock_getres`
не удостоверяет физическую точность счётчика.
