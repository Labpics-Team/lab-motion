# Инспектор кадра

Сценарий для семейства преобразования представления r11: редактор съёмочного плана переносит один и тот же кадр из списка в инспектор и обратно. Подпись остаётся в приложении при быстром выборе другого кадра, повторном открытии и закрытии Escape. Это локальный потребитель, не отдельный runtime библиотеки.

Из корня репозитория: `pnpm install --frozen-lockfile`, затем `node examples/shot-inspector/prepare.mjs` и `node examples/shot-inspector/test.mjs`. Для просмотра: `pnpm exec vite --config examples/shot-inspector/vite.config.mjs`.

`prepare.mjs` пересобирает пакет и устанавливает его архив в каталог примера. Тест сверяет SHA-256 архива, манифеста и публичного экспорта `./projection` с receipt; изменённый source или архив отвергается. Откройте кадр, измените подпись, выберите другой до завершения движения, вернитесь Escape. Попробуйте узкий экран, RTL и кнопку «Без движения».
